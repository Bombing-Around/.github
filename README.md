# .github

Organization-level defaults for [Bombing Around](https://github.com/Bombing-Around).

| Path                | What it does                                                                                  |
| ------------------- | --------------------------------------------------------------------------------------------- |
| `profile/README.md` | The org profile page shown at [github.com/Bombing-Around](https://github.com/Bombing-Around). |
| `README.md`         | This file — describes the repo itself, and is not rendered on the profile.                     |

Editing `profile/README.md` changes the org landing page, so keep the project list in it in
sync with [bombing-around.github.io](https://bombing-around.github.io) (source:
[bombing-around.github.io](https://github.com/Bombing-Around/bombing-around.github.io)),
which carries the same list in `README.md` and `index.html`.
